# 工业无线温振监测系统

## v0.5 现场多设备兼容更新

- 预置 CBF0、CBF2、CBF3、CBF4、CBF5、CBF6 共 6 台现场设备及其 MAC 地址。
- 默认现场串口改为 COM3，同时连接上限保持 5 台。
- 串行发起蓝牙连接，避免 EW-DTU02 同时收到多条连接命令后返回 `CNN_BUSY`。
- 自动轮换扫描地址/自动地址、安全连接/普通连接、MTU247/MTU23 等兼容方案。
- 前五次兼容尝试采用快速重试，随后才进入退避等待。
- 设备卡片直接显示连接失败原因及刚刚尝试的连接方案。

## v0.4 界面更新

- 首页精简为“设备采集状态”和“设备总览”。
- 每台设备提供独立实时监控页面，温度、速度、位移、频率分为四张图表。
- 速度、位移和频率图同时显示 X/Y/Z 三轴曲线，并使用固定颜色区分。
- 图表按真实时间绘制时间轴，可输入分钟数动态查看当前时间以前的数据。
- 设备设置中可以删除设备及其历史记录，删除前会二次确认。
- 修复添加设备窗口右上角关闭时触发表单必填校验的问题。

面向 WTVB01-BT50 与 EW-DTU02 网关的本地采集、轮询调度、SQLite 存储和网页实时监控原型。

## 直接运行（推荐）

进入 `release\WTVB-Monitor`，双击 `WTVB-Monitor.exe`。程序会自动打开监控网页；命令窗口需要保持打开，关闭窗口即停止采集。该版本已经包含 Python 运行环境，迁移到另一台 Windows 11 电脑时复制整个 `WTVB-Monitor` 文件夹即可。

## 当前功能

- 可配置 1～7 路并发连接，默认 5 路
- 可配置 1～5 分钟轮询采集窗口，默认 3 分钟
- 网页选择设备后优先连接；满连接时抢占一个普通轮询通道
- 通过 MAC 识别设备，不依赖会变化的网关连接句柄
- 解析 WTVB01-BT50 的 `55 61` 温振数据帧
- SQLite 保存实际样本，未采集时不写假零
- WebSocket 实时更新首页和焦点设备曲线
- 每台传感器可分别设置温度、速度、位移、频率的预警和报警阈值
- 排队或断开期间显示空值并保留历史数据缺口，不制造虚假零值
- 内置 7 台模拟设备，便于单传感器阶段验证网页和调度
- 网页中可直接切换模拟网关/真实串口网关，无需手改配置文件
- 设备详情中查看各轴速度、位移、频率、振动角及可用扩展字段
- 真实网关模式下分别显示串口状态、是否扫描到传感器、RSSI 和 BLE 数据连接结果

## 网关正常但没有数据时

网页显示“串口通信正常”和“已发现”代表 USB/485 与扫描链路正常；只有显示“已连接并接收数据”才表示传感器真正建立连接。`-75 dBm` 以下会提示信号弱。若显示 `BLE 34` 或连接超时，请关闭手机及厂家软件中的传感器连接，把传感器和网关移到 0.5 米以内、避开金属遮挡后重试。

## 开发运行

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m app
```

浏览器打开 `http://127.0.0.1:8000`。

## 切换真实网关

先关闭厂商上位机，在网页“采集设置”中选择“真实 EW-DTU02 网关”，确认串口为 `COM5` 后保存。应用会立即切换；模拟设备在真实串口模式下会自动忽略。

## 数据与迁移

- 配置：`config/settings.json`
- 数据库：`data/monitor.db`
- 整个目录可以复制到另一台 Windows 11 电脑。
- `release\WTVB-Monitor` 是已生成的独立 Windows 程序。

## 安全约定

- 应用仅自动发送查询、扫描、连接、断开和通知接收指令。
- 不自动修改传感器寄存器或网关永久参数。
- 串口不能与 WitMotion 厂商上位机同时打开。
