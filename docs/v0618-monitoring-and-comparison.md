# v0.6.18 监控界面与项目对照（2026-10-10）

## 使用基线

用户反馈 v0.6.17 已能通过 Windows 电脑内置蓝牙稳定读取并保存，实际并发提升到七台。这是用户现场验证结果；本次没有再次进行七台实物验收，也不开展网关测试。驱动、协议解析、调度和数据库保存代码沿用原版。

## 与 wtvb01-bt50-visor 的差异

依据 2026-10-10 读取的公开 [README](https://github.com/JoseSacristan/wtvb01-bt50-visor/blob/main/README.md)、[BLE 与协议源码](https://github.com/JoseSacristan/wtvb01-bt50-visor/blob/main/WitMotion.py) 及 [GUI 源码](https://github.com/JoseSacristan/wtvb01-bt50-visor/blob/main/WitMotionGUI.py)，没有运行该仓库的脚本。

| 方面 | 对照项目 | 本项目 |
|---|---|---|
| 使用定位 | Linux / BlueZ、Tkinter 单传感器振动观察 | Windows 浏览器界面、多传感器持续采集 |
| 蓝牙连接 | 同样使用 Bleak 和 FFE5/FFE4；GUI 只有一个 BLE 数据源，断开后没有自动重连循环 | 多设备 MAC 管理、调度、会话清理、逐台自动重试；七路已获用户实测反馈 |
| 历史与保存 | 内存中保存 10–120 秒窗口，支持 JPG 截图；未见 SQLite 长期记录、历史分页或 CSV 导出 | SQLite 历史保存、最多七天区间查询、分页记录及 CSV 导出 |
| 分析视图 | 振动速度柱形、峰值保持、窗口均值/最大值、固定机组类型的振动分区、按像素保留峰值 | 温度、三轴速度/位移/频率趋势、当前值、自定义设备报警阈值 |
| 传感器设置 | GUI 可写入输出频率，10/20/50/100 Hz；源码另提供可选永久保存 | 当前保持只读采集，不写入输出频率或传感器寄存器 |

两者的 BLE UUID 相同，但运行平台、设备数量与数据用途不同。对照源码中的短帧容忍和服务缺失后继续订阅也不同于本项目的完整帧及服务验证，不能据此判断它在本机的连接稳定性更高。输出频率调节还会影响七台的无线负载，不属于本次界面改动。

其窗口均值/峰值、实际接收频率、保留峰值的绘图方法值得作为后续分析功能参考，本次没有自动引入这些功能或固定振动分区阈值。

## 本次界面

- X 红、Y 绿、Z 蓝，实时与历史曲线、图例和当前值一致。
- 悬停显示游标时间与最近实际样本时间、值和单位。历史趋势按原有方式抽样，悬停取得的是图上显示的样本；精确采集记录仍从历史表格或 CSV 读取。无记录和缺失字段不显示伪造零值。
- 快捷范围统一为 1/5/10/30 分钟、1/3/6/24 小时、3/5/7 天，同时保留原有自定义方式。

## 验证与升级

Node 回归覆盖轴色、图例配色、悬停时间/最近样本、缺失/空数据、高分屏坐标、事件复用和全部快捷档位。Edge 无界面浏览器使用模拟接口数据验证实时/历史交互、所有档位、自定义输入、宽屏与 390px 窄屏布局，无页面脚本错误；此检查不代表新的硬件采集实测。原有自动测试和 Windows EXE 自检由发布构建执行。

退出旧程序，备份并复制旧版 `data` 和 `config` 到新版 EXE 同目录，以保留历史、设备和已经工作的七路配置。勿将模拟界面检查数据装入实际数据库。
